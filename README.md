# KIREI MomentSs
**KIREI MomentSs** adalah website restoran Jepang yang dibuat sebagai project tugas pelatihan. Website ini menampilkan informasi restoran, menu makanan dan minuman, serta halaman reservasi dengan menggunakan HTML dan juga CSS.

---
## 1. Tentang Project
KIREI MomentSs merupakan website restoran dengan konsep dan desain bertema Jepang.
### A. Tujuan
Project ini dibuat untuk:
1. Membuat website restoran menggunakan HTML dan CSS.
2. Menerapkan struktur halaman website.
3. Membuat navigasi antar halaman.
4. Menampilkan informasi restoran dan menu.
5. Membuat halaman reservasi.

---
## 2. Fitur Website
Website KIREI MomentSs memiliki beberapa halaman utama:
| No. | Fitur        | Keterangan                                         |
| --- | ------------ | -------------------------------------------------- |
| 1   | Home         | Menampilkan halaman utama restoran                 |
| 2   | About        | Menampilkan informasi restoran, pemilik, dan staff |
| 3   | Menu         | Menampilkan daftar makanan, minuman, dan dessert   |
| 4   | Reservasi    | Menampilkan formulir reservasi                     |

---
## 3. Struktur Project
Struktur file project KIREI MomentSs:
```text
KIREI MomentSs/
│
├── index.html
├── about.html
├── menu.html
├── order.html
├── style.css
│
└── Assets/
    ├── Gambar
    ├── Logo
    └── Audio
```

### Keterangan File
| File         | Fungsi                            |
| ------------ | --------------------------------- |
| `index.html` | Halaman utama                     |

| `menu.html`  | Halaman daftar menu               |
| `order.html` | Halaman reservasi                 |
| `style.css`  | Mengatur tampilan website         |
| `Assets/`    | Menyimpan gambar, logo, dan audio |

## 5. Tampilan Website
Website menggunakan konsep desain bertema Jepang dengan beberapa elemen pendukung, seperti:
1. Logo restoran.
2. Gambar restoran dan makanan.
3. Gambar Gunung Fuji.
4. Informasi pemilik dan staff.
5. Navigasi antar halaman.
6. Formulir reservasi.
7. Link media sosial.
8. Musik sebagai elemen pendukung.
   
---
## 6. Catatan
Project ini merupakan website restoran fiktif yang dibuat untuk keperluan tugas pelatihan.
Form reservasi pada website masih berupa tampilan frontend dan belum terhubung dengan database atau backend.
